# UI baseline

ISSUE-001 / REQ-002: UI-001 overview and product catalog; UI-002 product dialog and movement dialog; UI-003 stock history with pagination; UI-004 low-stock catalog; UI-005 Smart Health Monitor. Forest-green sidebar, warm lime accent, neutral cards and compact inventory tables.

Navigation collapses behind a toggle on mobile. Tables scroll horizontally, card grids collapse, forms use native accessible labels and modal dialogs. Empty results, load failures with retry, inline validation errors, confirmation before deletion and live success status are included. Server remains the authority for validation and stock bounds.
