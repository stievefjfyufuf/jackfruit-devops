# Change Request

## Change ID

CR-002

## Request

Add executable IaC security scanning for `Dockerfile` and `docker-compose.yml`,
extend localhost-only API negative tests, and record an OWASP Top 10 matrix from
code and real test evidence.

## Type and scope

Normal-priority security hardening linked to ISSUE-001 / REQ-003 / AC-003.
Scope is limited to application code, tests, GitHub security workflow, scripts,
and documentation on `devsecops-security-audit`. Production Jenkins, VPS,
production data, `main`, push, and merge are out of scope.

## Impact analysis

| Artifact | Before | After | Risk |
|---|---|---|---|
| `src/app.js` | Unsupported verbs on known API paths fell through to 404 | Known resources return JSON 405 plus `Allow` | Low, intentional API contract hardening |
| `test/app.test.js` | Invalid body/bounds coverage | Adds verb, content type, repeated query, and numeric boundary checks | Low, isolated temp DB |
| `scripts/security-scan.js` | SAST/secrets/SCA only | Adds pinned Trivy IaC command | Low; scanner never starts application |
| GitHub workflow | No IaC stages | Adds pinned Trivy and KICS stages | Low; security CI only |
| audit docs | No OWASP test matrix | Records evidence and explicit untested categories | Low |

## Verification, results, and rollback

`npm.cmd test` passed 13 tests with 0 failures on 2026-11-26. Trivy 0.76.2
ran locally against the repository and wrote the original JSON report to
`audit-evidence/trivy-iac.json`: Dockerfile, 20 successful checks, 0 HIGH or
CRITICAL failures. Docker Compose was not detected by Trivy; KICS is configured
for it in CI but could not run locally because Docker/KICS are unavailable.

Rollback is a targeted reversion of the CR-002 files. No migrations, stored
data, service process, or remote state was modified.

## Approval gate and routing

The course assessor must supply/confirm the official PDF rubric mapping and
review a genuine CI KICS run before C4 can be considered PASS. Route to
implementation and automated testing; update the baseline only after that
evidence exists.
